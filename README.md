# Help Desk

Learning project built with Java 17, Spring Boot, Spring MVC and Thymeleaf.

## Features

- home page
- about page
- support contacts page
- FAQ page
- Bootstrap 5 and custom CSS

## Run

1. Install JDK 17.
2. Start the application:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

3. Open:

   ```text
   http://localhost:8080
   ```
